Intro / Module Context

This e-Portfolio represents my learning journey throughout the Advanced Object-Oriented Design and Programming (AOODP) module. The module enhanced my ability to apply advanced object-oriented principles and design patterns to create secure, scalable, and maintainable software systems. It also strengthened my understanding of architectural design, concurrency control, and the integration of artificial intelligence and data-driven components in modern applications.

The portfolio presents a collection of practical artefacts — including coding exercises, design case studies, and the final capstone project — that demonstrate how theoretical concepts were translated into working software. Each artefact is aligned with the module’s learning outcomes and showcases my development of analytical, technical, and professional competencies.

Overall, this work reflects the progression from mastering OOP fundamentals to designing enterprise-level solutions using secure coding practices, multithreading, and advanced architectural strategies that support long-term software evolution.

Summary Reflection

These outcomes show my evolution from theory to practice in secure, maintainable, and scalable software design.

Secure Coding Practices

I integrated security at every stage of development, adopting a defense-in-depth approach combining validation, encryption, and safe exception handling.

In the Thread-Safe Banking System, inputs were validated, credentials hashed with bcrypt, and RLock used for safe concurrent operations.

In the Capstone Project, I implemented parameterized queries and RBAC to prevent injections and privilege escalation while ensuring secure error handling.

These methods align with OWASP and NIST SP 800-53 standards, embedding privacy and integrity within the architecture.

Advanced OOP Principles

This section highlights my ability to apply advanced object-oriented programming (OOP) principles such as abstraction, encapsulation, inheritance, and polymorphism to develop scalable and maintainable software systems. These principles collectively form a foundation for reliable and extensible architectures.

In the Thread-Safe Banking System, I used encapsulation to protect data integrity, ensuring balance updates only through controlled methods. Each transaction type (deposit, withdrawal, transfer) shared a unified interface — a clear demonstration of polymorphism. Inheritance simplified code reuse, while abstraction defined flexible interfaces for specialized banking operations.

During my Capstone Project, I designed a modular class hierarchy for the analytics engine. The Factory Method pattern was used to dynamically create components such as data preprocessors and model evaluators, minimizing coupling between layers.

Adhering to SOLID and GRASP principles allowed me to produce testable, maintainable, and professional-grade code — strengthening both my technical expertise and my understanding of software craftsmanship.
