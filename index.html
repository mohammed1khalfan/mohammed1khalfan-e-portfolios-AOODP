Intro / Module Context

This e-Portfolio represents my learning journey throughout the Advanced Object-Oriented Design and Programming (AOODP) module. It documents the transition from theory to practice through secure, scalable, and maintainable solutions.

The module developed my understanding of architecture, design patterns, multithreading, and secure coding. Artefacts like the Thread-Safe Banking System and the Capstone Project reflect growth in both academic and professional capability.

Learning Outcomes — Evidence Map

  • Design Patterns: Applied Strategy, Adapter, and Composite patterns for reusability and flexibility.
  • Architectural Design: Created layered systems ensuring scalability and robustness.
  • AI Integration: Developed modular data pipelines for machine learning compatibility.
  • Advanced OOP: Used abstraction, encapsulation, and polymorphism to solve complex problems.
  • Secure Coding: Embedded validation, parameterized queries, and encryption into all solutions.

Secure Coding Practices

Security was applied at every stage through a defense-in-depth strategy.

In the Thread-Safe Banking System, I validated inputs, secured passwords with bcrypt, and used RLock to avoid race conditions.

In the Capstone Project, I implemented parameterized SQL queries and RBAC to prevent injections and escalation attacks. These align with OWASP and NIST SP 800-53 frameworks.

Advanced OOP Principles

Applied core OOP concepts: abstraction, inheritance, encapsulation, and polymorphism.

In the Banking System, encapsulation safeguarded balance integrity, inheritance streamlined transactions, and polymorphism unified interfaces.

In the Capstone Project, modular hierarchies using the Factory Method improved extensibility and maintained clean architecture.

Design Patterns

Design patterns provided structured and reusable solutions to common challenges.

  • Strategy Pattern — dynamic execution of transactions in the Banking System.
  • Adapter Pattern — seamless module integration.
  • Bridge Pattern — decoupled logic from data layers in the Capstone Project.
  • Observer Pattern — event-driven updates in analytics modules.

These patterns enhanced modularity, reusability, and scalability across projects.

Software Architecture

Architectural design ensured scalability, security, and maintainability through layered and modular systems.

In the Capstone Project, a Layered MVC Architecture separated UI, logic, and data components. Security features like authentication and encryption were embedded as part of secure-by-design.

Exploration of Microservices and Event-Driven styles provided insight into distributed system trade-offs.

AI & Data Science Adaptability

Designed systems to integrate smoothly with AI models and data analysis workflows.

In the Capstone Project, modular data pipelines were developed to preprocess and feed information into predictive models. APIs were created for dynamic model updates without modifying the system core.
